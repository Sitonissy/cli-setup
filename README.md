# cli-setup

Dotfiles and automated terminal setup for macOS and Ubuntu.

## Stack

* Config management: GNU Stow
* Shell: Zsh + Oh My Zsh + Powerlevel10k
* Theme: Dracula PRO Van Helsing (optional, encrypted archive)
* Tools: `zoxide`, `eza`, `bat`, `ripgrep`, `fzf`, `lazygit`, `zellij`, `git-delta`

## Installation

```bash
git clone [https://github.com/Sitonissy/cli-setup.git](https://github.com/Sitonissy/cli-setup.git) ~/_git/cli-setup
cd ~/_git/cli-setup
./install.sh
